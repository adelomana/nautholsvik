# nautholsvik
Computational tools to quantify non-additive effects on gene expression.

These scripts are available to support a submitted manuspript entitled:

_[Differentiation status determines the effects of IFNγ on the expression of PD-L1 and immunomodulatory genes in melanoma](https://biosignaling.biomedcentral.com/articles/10.1186/s12964-024-01963-6)_
